First release

Sends each link to the right browser, and the right profile inside it.

  • Rules by host, url prefix, a word in the path, or a regular expression — the most specific one wins, whatever order they are in.
  • Dia, Arc, Chrome, Brave, Edge, Vivaldi, Safari, Firefox and Zen, each addressed the way it actually allows.
  • A tab already showing the link is focused rather than opened twice, wherever the browser allows that to be asked.
  • Links for Linear, Figma, Notion, Slack, Teams, Asana, Discord, Zoom and Spotify can skip the browser entirely.
